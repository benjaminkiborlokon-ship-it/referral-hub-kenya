Referral Hub Kenya prototype

Includes the mobile-first website/PWA foundation, two referral offers, search,
native share, light/dark mode, PWA manifest, and entry points for promotion and ads.

Production items still requiring secure backend/deployment:
admin authentication and recovery, database-backed unlimited offers, payment
verification, Daraja, ad accounting/anti-abuse, file storage, and production
legal/store compliance.

Run with Node.js:
npm install
npm start
Then open http://localhost:3000
